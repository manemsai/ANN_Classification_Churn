# 📊 ANN Classification - Churn Prediction  

## 📌 Overview  
This project focuses on predicting **customer churn** using an **Artificial Neural Network (ANN)**. The model is trained on customer data to classify whether a customer is likely to churn or not, helping businesses improve customer retention strategies.  

## 🚀 Features  
- **ANN-based Classification Model**  
- **Preprocessing of Customer Data**  
- **Evaluation Metrics**: Accuracy, Precision, Recall, F1-score, ROC-AUC  
- **Hyperparameter Tuning for Optimization**  
- **Scalability for Deployment**  



## 🔧 Installation  
1. Clone the repository:  
   ```bash
   git clone https://github.com/manemsai/ANN_Classification_Churn.git
   cd ANN_Classification_Churn
   ```  
2. Install dependencies:  
   ```bash
   pip install -r requirements.txt
   ```  

## 🛠 Usage  
1. **Train the Model:**  
   ```bash
   python train.py
   ```  
2. **Run the App (if deployed as a web app):**  
   ```bash
   python app.py
   ```  
3. **Evaluate Model Performance:** Check accuracy, precision, recall, and confusion matrix.  

## 📖 Technologies Used  
- **Python**  
- **TensorFlow / Keras** (for ANN model)  
- **Scikit-Learn** (for data preprocessing and evaluation)  
- **Pandas & NumPy** (for data manipulation)  
- **Matplotlib & Seaborn** (for visualization)  

## 📊 Dataset  
- The dataset contains customer details such as **demographics, transaction history, and engagement metrics**.  
- Target variable: **Churn (Yes/No)**  

## 🔥 Model Architecture  
- Input Layer  
- Hidden Layers (with **ReLU activation**)  
- Output Layer (with **Sigmoid activation**)  

## 📈 Performance Metrics  
- **Accuracy**  
- **Precision & Recall**  
- **F1-Score**  
- **ROC-AUC Curve**
